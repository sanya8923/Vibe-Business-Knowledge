## Что это

GuruScribe.ru — российский сервис транскрибации: речь → текст, диаризация (разделение по говорящим), AI-саммари, экспорт, заявлено 90+ языков. Подписка 690–2990 ₽/мес.

## Зачем смотрели

Направление обратное тому, что нужно этапу «озвучка» в контент-конвейере (там нужен TTS текст→речь, а не STT речь→текст). Единственная точка пересечения — точные пословные таймкоды для караоке-субтитров.

## Ключевая находка: есть API

`POST https://api.guruscribe.ru/v1/transcribe/`
- 0.3 ₽/мин — транскрибация
- 0.6 ₽/мин — с диаризацией
- +0.05 ₽/мин — AI-саммари

Формат ответа (пословные таймкоды или только сегменты по абзацам) нигде публично не задокументирован — открытый вопрос, без которого сравнение с альтернативами (например, WhisperX) остаётся гипотезой, а не фактом.

## Юридический блокер (по тексту ToS)

Условия использования прямо запрещают передавать право пользования сервисом третьим лицам; встраивание в коммерческий продукт требует **письменного согласия** правообладателя. Для коммерческого автопайплайна это значит: нельзя просто вызывать API без разрешения.

## Другие риски

- Ответственность за качество распознавания снята с сервиса — заявлена обязательная ручная проверка расшифровок
- Нет SLA (только формулировка «круглосуточный доступ, кроме профилактики»)
- Данные хранятся до 1 года, страна серверов не указана, использование для обучения моделей не оговорено
- Вендор — физлицо-ИП (ОГРНИП 318246800061657), не юрлицо
- Заявленные «5/5 на Отзовике» и «50К+ пользователей» независимо не подтверждаются — целевой поиск не нашёл ни одного стороннего отзыва, ни хорошего, ни плохого

## Вывод

Не встраивать в автопайплайн без отдельного разрешения. Единственное безопасное применение прямо сейчас — расшифровка чужих роликов по ссылке вручную через веб-интерфейс, как исследовательский инструмент для этапа «контент-план», без нарушения ToS.
