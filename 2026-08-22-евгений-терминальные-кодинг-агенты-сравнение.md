# Claude Code vs Codex vs Pi vs Reasonix — big picture по терминальным кодинг-агентам

Повод: в чате скинули pi.dev как что-то новое и интересное, дальше вспомнили
про DeepSeek-агента (Reasonix) — решили сравнить сразу все четыре, включая два
самых известных (Claude Code, Codex), чтобы был один документ-ориентир, а не
разрозненные впечатления из чатов.

**Оговорка по статусу:** цифры (звёзды, дата создания, лицензия) проверены
напрямую через GitHub API 22.08.2026 — это факт, не реклама. Возможности и
цены — из документации и обзоров, никто из четырёх агентов не тестировался
здесь руками на реальном проекте (Claude Code — исключение, им я и пишу этот
самый файл, так что его поведение подтверждено практикой; остальные три —
только по документации).

| GitHub-репо | anthropics/claude-code | openai/codex | earendil-works/pi | esengine/DeepSeek-Reasonix |

| Язык | Python | Rust | TypeScript | Go (один бинарник, без Node.js) |

**Первое, что удивляет:** самый популярный из четырёх (Claude Code, 142к звёзд)
— единственный с закрытым исходным кодом. Публичный репозиторий существует
только для issues и документации, самого кода в нём нет. Три остальных —
честный open source, можно читать и форкать.

## Возможности «из коробки»

| Возможность | Claude Code | Codex CLI | Pi | Reasonix |
|---|---|---|---|---|
| MCP (Model Context Protocol) | ✅ | ✅ | ❌ (собирать через расширения) | ✅ |
| Suб-агенты / параллельные роли | ✅ (Agent tool) | частично (через AGENTS.md) | ❌ | ✅ (executor + planner параллельно) |
| Режим планирования | ✅ (Plan mode) | ✅ | ❌ | ✅ |
| Система разрешений на действия | ✅ | ✅ | ❌ | ✅ |
| Чекпоинты / откат хода | есть (через git-интеграцию) | есть | ❌ | ✅ (per-turn checkpoints) |
| Скиллы / переиспользуемые инструкции | ✅ (Skill tool, огромная экосистема) | ✅ (`.codex/skills`) | ✅ (но нужно собирать самому — «примитивы», не готовое) | нет явного упоминания |
| Фоновое выполнение задач | ✅ | есть | ❌ (явно заявлено как отсутствующее) | ✅ («leave it running» — прямо в описании) |
| Песочница для выполнения | есть | есть (конфигурируемая) | нет упоминания | ✅ (workspace sandbox) |
| Интерфейсы | терминал, IDE-расширения | терминал, web, VS Code (9,8М установок), iOS, Bedrock | только терминал | терминал, десктоп, браузер, VS Code |

**Второе наблюдение:** Pi — единственный из четырёх, кто сознательно НЕ
реализует половину списка выше. Это не недоделка, а прямая философия:
«adapt Pi to your workflows, not the other way around» — минимальный каркас,
всё остальное строишь сам через расширения (50+ готовых примеров есть, но это
всё равно сборка, а не готовое решение). Три остальных — «комбайны», где всё
уже внутри.

## Деньги — где всё меняется местами

| | Модель оплаты | Реальная цена |
|---|---|---|
| **Claude Code** | подписка (входит в Claude Pro/Max/Team) или API напрямую | Pro $20/мес, Max 5x $100/мес, Max 20x $200/мес, Team от $25–30/пользователь/мес. API Sonnet 5: $2 / $10 за 1М токенов (вход/выход) |
| **Codex CLI** | входит в подписку ChatGPT (не продаётся отдельно) или API | Plus $20/мес, Pro 5x $100/мес, Pro $200/мес, Business $25–30/пользователь/мес |
| **Pi** | BYOK (свой ключ) — сколько стоит твой выбранный провайдер | если подключить Groq — фактически бесплатно/копейки, если Anthropic/OpenAI — по их тарифам |
| **Reasonix** | BYOK, только DeepSeek | V4-Flash: $0,14 за 1М вход / $0,0028 при кэш-попадании / $0,28 за 1М выход. В 10-70 раз дешевле подписок выше |

**Третье, главное для бюджета:** Claude Code и Codex — это, по сути, одна и
та же ценовая модель (подписка ChatGPT/Claude, $20–200/мес), просто от разных
компаний. Pi и Reasonix играют в другую игру — свой ключ вместо подписки, и
если ключ от Groq или DeepSeek, разница по деньгам не на проценты, а на
порядки. Reasonix специально построен вокруг дешёвого кэша DeepSeek — сессию
можно держать открытой часами, не боясь счёта.

## Доверие и риски

- **Claude Code / Codex** — официальные продукты крупных компаний, живут в вашем
  терминале с доступом к файлам и командам, но за ними стоит Anthropic/OpenAI
  напрямую — привычная модель ответственности.
- **Pi** — открытый код, разработчик с именем и репутацией (libgdx — реальный
  проверенный проект с 2010-х), но сам Pi — независимый проект, не продукт
  big tech.
- **Reasonix** — DeepSeek сам инструмент не делает и не аудирует, только
  упоминает как «поддерживаемую интеграцию» в доках. Ставя его — доверяете
  API-ключ и права на правку кода стороннему независимому разработчику.
  Открытый код (можно проверить самому), но ответственности вендора за ним нет.

## Кому что подходит

- **Уже платите за Claude/ChatGPT и хотите готовое решение без сборки** —
  Claude Code или Codex, выбор по личным предпочтениям, они очень близки по
  возможностям и цене.
- **Хотите гибкость по моделям и не боитесь настраивать самостоятельно** — Pi.
- **Важнее всего дешевизна и не жалко довериться независимому проекту** —
  Reasonix, особенно если уже есть ключ DeepSeek.
- **Нужна экосистема скиллов/плагинов прямо сейчас, без сборки с нуля** —
  Claude Code — самая большая и зрелая экосистема из четырёх на сегодня.
