# Hermes Agent: лучшие бесплатные облачные модели и инструкция по подключению

**Дата исследования:** 27 августа 2026 года
**Статус:** актуально на дату исследования; бесплатные модели, квоты и маршруты меняются без длительного уведомления.

## 1. Цель и область исследования

Документ сравнивает лучшие практически доступные бесплатные облачные модели, которые можно использовать как основной или вспомогательный LLM-бэкенд в Hermes Agent.

При ранжировании учитывались:

- качество модели по Artificial Analysis и профильным coding/agentic-бенчмаркам;
- способность работать с инструментами и многошаговыми агентными задачами;
- фактический контекст конкретного бесплатного API-маршрута;
- бесплатные квоты и устойчивость маршрута;
- совместимость с Hermes Agent;
- конфиденциальность и возможность использования запросов для обучения;
- сложность регистрации и подключения.

ARC Prize использовался как дополнительный индикатор абстрактного рассуждения. Он не заменяет проверку function calling, устойчивости длинных сессий, работы с файлами и терминалом.

## 2. Ключевой вывод

Для Hermes Agent нет одной бесплатной модели, которая одновременно была бы лучшей по качеству, квотам, приватности, длинному контексту и стабильности.

Практически оптимальна следующая связка:

1. **GLM-5.2 Free через OpenRouter** — основной бесплатный агент для сложных задач.
2. **Gemini 3.7 Flash через Google AI Studio** — самый сильный бесплатный вариант по общему интеллекту, но с ограниченной бесплатной квотой.
3. **MiniMax M3 Free через OpenRouter** — длинный контекст и мультимодальные задачи.
4. **Laguna S 2.1 Free через OpenRouter** — специализированный coding worker.
5. **Qwen3.8-27B через Groq Free** — сильная и быстрая модель, но лимит 8 000 токенов в минуту может мешать полному системному промпту Hermes.

Один ключ OpenRouter открывает доступ сразу к позициям 1, 3 и 4.

### Как интерпретировать рейтинг

- **Лучший практический основной бесплатный агент:** GLM-5.2 Free.
- **Лучшее разовое качество:** Gemini 3.7 Flash.
- **Лучший большой контекст:** MiniMax M3 Free.
- **Лучший специализированный coding worker:** Laguna S 2.1 Free.
- **Лучшие бесплатные суточные токены:** Qwen3.8-27B на Groq, но только если запрос помещается в минутный лимит.

Оценки Artificial Analysis приведены для повышенных режимов reasoning. Они показывают потенциал модели, но не гарантируют идентичный результат при настройках конкретного API-провайдера.

## 5. Где зарегистрироваться и какие ключи получить

### 5.1 OpenRouter

Нужен для GLM-5.2 Free, MiniMax M3 Free и Laguna S 2.1 Free.

1. Зарегистрироваться или войти в OpenRouter.
2. Открыть раздел API Keys.
3. Создать отдельный ключ для Hermes.
4. Сохранить его как:

```dotenv
OPENROUTER_API_KEY=sk-or-...
```

Базовая бесплатная квота OpenRouter:

- 50 запросов в сутки;
- 20 запросов в минуту.

После однократного приобретения не менее 10 USD кредитов потолок бесплатных моделей увеличивается до 1 000 запросов в сутки. Сами запросы к моделям с суффиксом `:free` остаются бесплатными.

Один пользовательский запрос в Hermes может вызвать несколько обращений к модели, поэтому 50 API-запросов не равны 50 полноценным агентным задачам.

### 5.2 Google AI Studio

Нужен для Gemini 3.7 Flash.

1. Войти в Google AI Studio под Google-аккаунтом.
2. Открыть страницу API Keys.
3. Нажать **Create API key**.
4. Скопировать ключ и сохранить как одну из переменных:

```dotenv
GOOGLE_API_KEY=...
```

или:

```dotenv
GEMINI_API_KEY=...
```

Hermes поддерживает оба имени. Платёжные данные для Free Tier обычно не требуются, однако доступность и конкретные лимиты определяются аккаунтом и проектом.

### 5.3 GroqCloud

Нужен для Qwen3.8-27B.

1. Зарегистрироваться в GroqCloud Console.
2. Открыть раздел API Keys.
3. Создать ключ.
4. Сохранить его как:

```dotenv
GROQ_API_KEY=gsk_...
```

Базовые лимиты Free Plan для `qwen/qwen3.8-27b` на дату исследования:

- 30 запросов в минуту;
- 1 000 запросов в сутки;
- 8 000 токенов в минуту;
- 2 000 000 токенов в сутки.

Точные лимиты конкретной организации следует проверять на странице Limits в GroqCloud Console.

## 6. Совместимость с Hermes Agent

Hermes Agent v0.20.4 уже поддерживает:

- OpenRouter как встроенный provider;
- Google Gemini как встроенный provider;
- именованные OpenAI-compatible custom providers, включая Groq.

Обновление не требуется для пяти моделей из основного рейтинга.

Hermes Agent v0.20.5 дополнительно получил `opencode-free` — анонимный provider без аккаунта и API-ключа. Это полезный аварийный fallback, но он не включён в основной рейтинг, поскольку набор моделей временный и может меняться.

## 7. Подключение без замены существующей основной модели

### 7.1 Принцип

Чтобы сохранить уже настроенную основную модель:

- не изменять секцию `model:` в `config.yaml`;
- не использовать `/model ... --global`;
- добавить только API-ключи и описание Groq provider;
- запускать бесплатную модель отдельной командой или переключать только текущую сессию.

CLI-аргументы `--provider` и `--model` являются override только для конкретного запуска.

### 7.2 Найти файлы конфигурации

```powershell
hermes config path
hermes config env-path
```

### 7.3 Сделать резервную копию в PowerShell

```powershell
$stamp = Get-Date -Format "yyyyMMdd-HHmmss"
$cfg = (hermes config path).Trim()
$envFile = (hermes config env-path).Trim()

Copy-Item $cfg "$cfg.bak-$stamp"

if (Test-Path $envFile) {
    Copy-Item $envFile "$envFile.bak-$stamp"
}
```

### 7.4 Добавить ключи

Открыть файл секретов:

```powershell
notepad (hermes config env-path)
```

Добавить только полученные ключи:

```dotenv
OPENROUTER_API_KEY=sk-or-...
GOOGLE_API_KEY=...
GROQ_API_KEY=gsk_...
```

Не добавлять кавычки, пробелы вокруг `=` и комментарии в строку ключа.

Альтернативный способ:

```powershell
hermes config set OPENROUTER_API_KEY "sk-or-..."
hermes config set GOOGLE_API_KEY "..."
hermes config set GROQ_API_KEY "gsk_..."
```

Следует учитывать, что такой способ может оставить значение ключа в истории команд оболочки.

### 7.5 Добавить Groq как именованный provider

Открыть конфигурацию:

```powershell
hermes config edit
```

Добавить Groq **в уже существующую** секцию `providers:`:

```yaml
providers:
  groq:
    api: https://api.groq.com/openai/v1
    key_env: GROQ_API_KEY
    transport: chat_completions
```

Если в файле уже есть верхнеуровневая секция `providers:`, нельзя создавать вторую. Нужно добавить блок `groq:` внутрь существующей секции.

Не добавлять следующий блок, если требуется сохранить текущую основную модель:

```yaml
model:
  provider: custom:groq
  default: qwen/qwen3.8-27b
```

### 7.6 Проверить конфигурацию

```powershell
hermes config check
hermes doctor
```

После изменения ключей и providers следует закрыть старый процесс Hermes и запустить новый. Для gateway:

```powershell
hermes gateway restart
```

## 8. Запуск каждой модели в отдельной сессии

Это самый безопасный способ: существующая основная модель не меняется.

### 8.1 GLM-5.2 Free

```powershell
hermes chat --provider openrouter --model z-ai/glm-5.2:free
```

### 8.2 Gemini 3.7 Flash

```powershell
hermes chat --provider gemini --model gemini-3.7-flash
```

### 8.3 MiniMax M3 Free

```powershell
hermes chat --provider openrouter --model minimax/minimax-m3:free
```

### 8.4 Laguna S 2.1 Free

```powershell
hermes chat --provider openrouter --model poolside/laguna-s-2.1:free
```

### 8.5 Qwen3.8-27B через Groq

Полный набор инструментов:

```powershell
hermes chat --provider custom:groq --model qwen/qwen3.8-27b
```

Если Groq возвращает 429 из-за 8K TPM, запустить свежую сессию с сокращённым набором инструментов:

```powershell
hermes chat --provider custom:groq --model qwen/qwen3.8-27b -t file,terminal
```

Даже с сокращёнными tools длинная память, большие инструкции или загруженные документы могут превысить минутную квоту.

## 9. Переключение внутри активного чата

После настройки providers можно использовать:

```text
/model openrouter:z-ai/glm-5.2:free
/model gemini:gemini-3.7-flash
/model openrouter:minimax/minimax-m3:free
/model openrouter:poolside/laguna-s-2.1:free
/model custom:groq:qwen/qwen3.8-27b
```

Не добавлять `--global`, если требуется сохранить прежнюю основную модель.

Для честного теста лучше открыть свежую сессию. Переключение длинного чата:

- сбрасывает prompt cache;
- заставляет следующую модель заново прочитать текущий контекст;
- может вызвать автоматическую компрессию;
- может не поместиться в 131K или 256K маршрута;
- быстрее расходует бесплатную API-квоту.

## 10. Быстрая схема выбора

| Задача | Рекомендуемая модель |
|---|---|
| Обычная сложная работа с tools | GLM-5.2 Free |
| Сложное рассуждение или проверка результата | Gemini 3.7 Flash |
| Большой документ, изображения, видео, длинная история | MiniMax M3 Free |
| Рефакторинг, терминал, тесты, coding agent | Laguna S 2.1 Free |
| Короткие интерактивные задачи с небольшим контекстом | Qwen3.8-27B на Groq |

## 11. Типовые ошибки

### Provider не появляется в `/model`

Причины:

- ключ не сохранён в `.env`;
- старый процесс Hermes не перечитал переменные;
- provider ещё не настроен;
- Groq-блок добавлен с ошибкой YAML.

Действия:

```powershell
hermes config check
hermes doctor
```

Затем перезапустить Hermes.

### OpenRouter возвращает 429

Возможные причины:

- исчерпаны 50 бесплатных API-запросов в сутки;
- upstream free provider временно перегружен;
- Hermes сделал несколько model calls внутри одной задачи.

Решение: переключиться на Gemini, Groq или другую бесплатную OpenRouter-модель.

### Groq возвращает 429 при первом сообщении

Наиболее вероятная причина — системный промпт, память и tool schemas превысили 8K TPM.

Решения:

- начать новый пустой чат;
- сократить toolsets;
- временно не загружать большую память и документы;
- использовать GLM-5.2 Free или MiniMax M3 Free вместо Groq.

### Модель не находится в интерактивном списке

Каталог Hermes может отставать от каталога провайдера. Использовать точный model ID через `hermes chat --provider ... --model ...`.

## 12. Конфиденциальность

Бесплатный инференс не следует считать приватным по умолчанию.

- Google указывает, что данные Free Tier Gemini могут использоваться для улучшения продуктов.
- Poolside предупреждает, что входы и выходы бесплатной Laguna S 2.1 могут использоваться для обучения и улучшения моделей.
- OpenRouter позволяет запретить маршрутизацию к providers, которые могут обучаться на данных. Это можно настроить в Privacy Settings либо через `provider_routing.data_collection: "deny"`. После запрета часть бесплатных endpoints может исчезнуть.
- Groq по умолчанию не сохраняет customer data обычных inference-запросов, кроме ограниченных случаев, необходимых для отдельных функций, диагностики надёжности или расследования злоупотреблений.

Рекомендуемая политика:

- не передавать бесплатным endpoints секреты, API-ключи, персональные данные и закрытые документы;
- не отправлять приватный исходный код без проверки data policy конкретного endpoint;
- хранить ключи только в `.env`, не в `config.yaml`, промптах и репозиториях;
- включить маскирование секретов Hermes:

```powershell
hermes config set security.redact_secrets true
```

## 13. Дополнительный fallback без регистрации

Начиная с Hermes Agent v0.20.5 доступен provider `opencode-free`:

- аккаунт не нужен;
- API-ключ не нужен;
- запросы отправляются анонимно;
- набор бесплатных моделей может меняться.

После обновления:

```powershell
hermes update
```

Внутри чата:

```text
/model free
```

Этот маршрут удобен как аварийный резерв, но хуже фиксированной модели для воспроизводимых агентных задач.

## 14. Итоговая рекомендуемая конфигурация

Минимально достаточный набор учётных записей:

1. OpenRouter — один ключ для трёх основных бесплатных моделей.
2. Google AI Studio — сильный независимый резерв.
3. GroqCloud — быстрый резерв с большой суточной token-квотой.

Рекомендуемый порядок использования:

```text
GLM-5.2 Free
→ Gemini 3.7 Flash
→ MiniMax M3 Free
→ Laguna S 2.1 Free
→ Qwen3.8-27B / Groq
→ OpenCode Free как keyless fallback
```
